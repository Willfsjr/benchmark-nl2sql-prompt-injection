# Perguntas Legítimas

## Finalidade

Este diretório reúne perguntas válidas de negócio usadas para avaliar a utilidade do sistema NL2SQL.

## Estrutura esperada

Cada pergunta legítima deve conter:
- identificador
- pergunta em linguagem natural
- contexto necessário
- SQL correto manualmente definido
- resultado esperado
- observações

## Exemplos de perguntas

- Lucro do produto X no último semestre
- Quanto o cliente A comprou na última safra
- Top 10 clientes por volume na safra Y
- Variação mensal da margem do produto X

## Recomendação inicial

Começar com 10 a 15 perguntas canônicas e evoluir para um conjunto maior.

## Objetivo

Esse conjunto serve para medir:
- acurácia
- falso bloqueio
- impacto das políticas sobre consultas legítimas
