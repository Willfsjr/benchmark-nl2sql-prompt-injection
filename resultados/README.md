# Resultados do Benchmark

## Finalidade

Este diretório reúne os resultados obtidos na execução do benchmark em diferentes configurações experimentais.

## Estrutura sugerida

- `tabelas/`
- `graficos/`
- `logs/`
- `comparativos/`
- `analise.md`

## O que registrar

### Por configuração
- quantidade de consultas executadas
- métricas de segurança
- métricas de utilidade
- métricas operacionais
- métricas de governança

### Por cenário
- perguntas legítimas
- prompts adversariais
- falhas observadas
- bloqueios indevidos
- evidências registradas

## Comparações principais

- Config 0 vs Config 1
- Config 1 vs Config 2
- Config 2 vs Config 3
- trade-offs entre segurança e utilidade
- impacto da auditoria e da evidência

## Objetivo final

Transformar a execução experimental em material comparável, reprodutível e útil para a análise do TCC.
